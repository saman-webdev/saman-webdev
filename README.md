### Hi, I'm Saman 👋

I'm a web developer. I've spent the last eight years building web applications with PHP, JavaScript and MySQL.

These days I'm building **[LogicUtil](https://logicutil.com)**, a set of free developer tools that run entirely in your browser. It has a JSON formatter, regex tester, Base64 and URL encoders, UUID generator, JWT decoder, hash and QR generators, image and color converters, and a Unix timestamp converter. There's no sign-up, no ads and no tracking, and nothing you paste is uploaded. It's available in 8 languages.
